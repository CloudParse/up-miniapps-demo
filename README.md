# Up Mini-App Demo

A complete Up mini-app with its backend: a React frontend that uses every capability of `@cloudparse/up-miniapps-sdk` (`frontend/`), a FastAPI backend (`backend/`) and a Docker Compose environment that runs the CloudParse backend and its infrastructure.

Run the commands in [`SETUP.md`](SETUP.md) to get started, then read [`AGENT.md`](AGENT.md): it holds the architecture, the quick start, the conventions and the review checklist. Then read `frontend/AGENT.md` and `backend/AGENT.md`.

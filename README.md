# Up Mini-App Template

A complete, minimal starting point for an Up mini-app: a React frontend (`up-miniapps-react-template/`), a FastAPI backend (`up-miniapps-template-python-backend/`) and a Docker Compose environment that runs the CloudParse backend and its infrastructure.

Run the commands in [`SETUP.md`](SETUP.md) to get started, then read [`AGENT.md`](AGENT.md): it holds the architecture, the quick start, the conventions and the review checklist. Then read `up-miniapps-react-template/AGENT.md` and `up-miniapps-template-python-backend/AGENT.md`.
